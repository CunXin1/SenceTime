# 微调副作用分析：代码题输出质量为何反而下降

> 现象：用 3 个新问题对比基座 vs 微调模型时，**代码题（Q2：写 is_palindrome）微调后的回答反而不如微调前**——更简短、缺注释、可解释性更差。本文分析原因并给出改进方向。
> 证据来源：`compare_qwen.md`、`compare_llama.md`。

---

## 一、现象与证据

### Qwen2.5-3B（Q2 代码题）
- **微调前（基座）**：给出「思路分点说明 → 完整代码 → 逐行解释」的结构化回答，解释详尽（因 400 token 预算被截断，说明其倾向于长而详细）。
- **微调后**：只给「简短代码 + 两三句说明」，省去了逐行解释和思路拆解。

### Llama-3.2-3B（Q2 代码题）—— 退化更明显
- **微调前（基座）**：代码带**规范 docstring**（`Args:` / `Returns:` 说明）、有注释、示例齐全，工程可读性好。
- **微调后**：代码**去掉了 docstring**，注释精简，甚至**缩进退化为单空格**（`\n ` 而非 4 空格），可解释性和规范性明显下降。

> 小结：两个模型在代码题上都出现「**从详解式 → 极简式**」的风格坍缩，Llama 还伴随格式规范性下降。而文字类问题（Q1 概念、Q3 推荐书）微调前后差异很小甚至微调后更顺。这说明退化是**领域相关**的，集中在代码这类训练语料未覆盖的能力上。

---

## 二、根因分析

### 1. 训练语料构成失衡：几乎没有代码（最主要原因）
本周三个数据集全是**中文文字问答**：
- `alpaca_gpt4_zh`（GPT-4 生成中文指令）、`coig_pc`（中文通用指令）、`sharegpt_zh`（中文多轮对话）。

其中代码类样本占比极低。SFT 的本质是「用数据分布去塑造输出分布」——训练集里没有「写带注释/详解代码」的范式，模型自然不会强化这项能力，反而被海量「简洁中文文字回答」的样本**稀释**掉了基座原有的代码书写习惯。

### 2. 风格坍缩（distribution shift）
`alpaca_gpt4_zh` 等语料的回答普遍**简短、直接**。3 epoch 训练后，模型的输出分布向这种「短平快」风格收敛，压制了基座原本「结构化、分点、带解释」的长回答倾向。代码题最吃「解释与规范」，因此受损最明显。

### 3. 轻度灾难性遗忘 / 对齐税（alignment tax）
在**窄分布**数据上做 SFT，会让模型在**训练分布外**的能力上退化——这就是「对齐税」。基座 Qwen2.5-3B-Instruct / Llama-3.2-3B-Instruct 本已在海量含代码的数据上对齐过；我们再用纯文字语料 SFT，相当于让它「偏科」，把一部分代码能力覆盖掉了。
- LoRA 只训 0.4% 参数，遗忘比全参微调轻，但如上所示**仍然可见**。
- `num_train_epochs: 3` + `lora_target: all` + `lr 1e-4` 都会放大这种向训练风格的过拟合。

### 4. 基座已足够强 → 微调更容易「帮倒忙」
两个基座都是已对齐的 Instruct 模型，代码能力已相当好。用一份不含代码、风格单一的语料去 SFT，边际上**更可能损害而非提升**它未被训练覆盖的能力。若基座是未对齐的 base 模型，同样数据反而会带来明显提升——这也解释了为什么文字题提升有限、代码题还退步。

---

## 三、改进方向

| 方向 | 做法 |
|---|---|
| **数据配比** | 混入代码指令数据（如 `code_alpaca_zh`、`magicoder`、`self-oss-instruct`），让训练分布覆盖代码，避免能力盲区 |
| **能力回放（replay）** | 掺入一定比例基座擅长的通用/代码样本，缓解灾难性遗忘 |
| **降低过拟合强度** | 减少 epoch（1~2）、调低 lr、或缩小 `lora_target`（只训 q/v），减小对基座的扰动 |
| **多维评测** | 评测集要覆盖代码 / 推理 / 写作多领域，别只看单一维度就下「变好/变差」结论 |
| **明确微调目标** | 若目标是垂直文字任务，代码退化可接受；若要保通用能力，必须做数据配比 |

---

## 四、结论

代码题退化**不是训练出了 bug，而是数据决定能力的必然结果**：
> **训练语料里没有代码，且风格单一简短 → 模型向文字短答收敛，代码这类未覆盖能力因分布漂移与轻度遗忘而退化。**

这正印证了本周主题「**数据是模型微调的粮食**」——喂什么，长什么；缺什么，退什么。要让微调**全面变好**而非「偏科」，关键在**语料的领域覆盖与配比**，而不是调训练参数。
