# ============================================================================
#  主环境依赖锁定 / Pinned dependencies for the main environment (.venv)
#  实测环境：Windows 11 + RTX 4090 (24GB) + Python 3.12.10
#
#  ★ 为什么全部钉死版本号
#    第 1~4 周的实验结论（eval loss 1.2630、DPO 拒答率 100% 等）是可复现性的地基。
#    transformers / peft / trl 任何一个漂移，重跑出来的数字就对不上交付文档，
#    整条实验链的可信度随之崩掉。第 6 周换机重建时正是靠这份 lock 把 eval loss
#    复现到小数点后三位（1.2630 vs 1.2629）。
#    Every version is pinned: the Week1-4 numbers are the reproducibility baseline.
#
#  ★ LLaMA-Factory 必须 --no-deps 安装（见 README 的「安装」一节）
#    下面 datasets / accelerate / peft / trl 四个版本正好卡在 LF 允许范围的**上界**，
#    直接 `pip install -e ./LLaMA-Factory` 会把它们全部降级。
#    LF must be installed with --no-deps or it downgrades four packages below.
#
#  ★ 本文件只覆盖主环境。多模态(.venv-vlm)、Agent(.venv-agent)、
#    WSL 里的量化/服务环境各自独立，原因见 README「为什么有五个虚拟环境」。
