## math-01（math）

**题目**：鸡兔同笼：笼子里共有 35 个头、94 只脚，问鸡和兔各有多少只？请给出完整推理过程。

### Model-A

2x + 4y = 94 （脚的数量）
接下来，我们可以使用代数方法解这个方程组。
首先，我们可以将第一个方程变形为 y = 35 - x，然后将其代入第二个方程中：
2x + 4(35 - x) = 94
化简得：
2x + 140 - 4x = 94
整理得：
-2x = -46
解得：
x = 23
将 x 的值代入 y = 35 - x 中，得到：
y = 35 - 23 = 12
因此，鸡有 23 只，兔有 12 只。

## math-03（math）

**题目**：一个水池，甲管单独注水 6 小时注满，乙管单独注水 4 小时注满。两管同时打开，需要多少小时注满水池？

### Model-A

设水池的容积为 V 升。

甲管单独注水的速度为 V/6 升/小时，乙管单独注水的速度为 V/4 升/小时。

当两管同时打开时，它们的注水速度之和为 (V/6 + V/4) 升/小时。

化简得：(2V + 3V)/12 = 5V/12 升/小时。

所以，两管同时打开时，注满水池需要的时间为 V/(5V/12) = 12/5 = 2.4 小时。

因此，两管同时打开需要 2.4 小时注满水池。

### Model-B

设水池的容积为 V 升。

甲管每小时注水 V/6 升，乙管每小时注水 V/4 升。

当两管同时打开时，它们每小时共同注水 (V/6 + V/4) 升。

设两管同时打开需要 x 小时注满水池，则有：

(V/6 + V/4) * x = V

化简得：(2V + 3V)/12 * x = V

即：5V/12 * x = V

解得：x = 12/5 = 2.4

所以，两管同时打开需要 2.4 小时注满水池。

### Model-C

设水池的容积为 V 升。
甲管每小时注水 V/6 升，乙管每小时注水 V/4 升。
两管同时打开时，每小时注水 V/6 + V/4 = 5V/12 升。
因此，注满水池需要的时间为 V / (5V/12) = 12/5 = 2.4 小时。

### Model-D

设水池的容积为 V 升。

甲管单独注水的速度为 V/6 升/小时，乙管单独注水的速度为 V/4 升/小时。

当两管同时打开时，它们的注水速度之和为 (V/6 + V/4) 升/小时。

所以，两管同时打开时，注满水池需要的时间为 V/(5V/12) = 12/5 = 2.4 小时。

因此，两管同时打开，需要 2.4 小时注满水池。

### Model-E

要解决这个问题，我们可以先计算每个小时内甲管和乙管各自可以注满水池的比例，然后将这两个比例相加得到两管同时工作时的效率。

甲管单独注水 6 小时注满水池，那么甲管每小时可以注满水池的比例为 \(1/6\)。

乙管单独注水 4 小时注满水池，那么乙管每小时可以注满水池的比例为 \(1/4\)。

当甲乙两管同时工作时，每小时可以注满水池的比例为 \(1/6 + 1/4 = 2/12 + 3/12 = 5/12\)。

这意味着，甲乙两管同时工作时，每小时可以注满水池的 \(\frac{5}{12}\) 部分。为了注满整个水池（即 1 全部），需要的时间为 \(1 \div \frac{5}{12} = \frac{12}{5} = 2.4\) 小时。

因此，甲乙两管同时打开，需要 2.4 小时注满水池。

> **参考要点**：1/(1/6+1/4) = 1/(5/12) = 2.4 小时（2 小时 24 分钟）。

## math-04（math）

**题目**：等差数列 3, 7, 11, 15, … 的第 50 项是多少？并给出通项公式。

### Model-A

这是一个等差数列，其中首项 a1 = 3，公差 d = 4。

根据等差数列的通项公式，第 n 项 an 可以表示为：
an = a1 + (n - 1)d

将 a1 = 3，d = 4 和 n = 50 代入上式，可得：
a50 = 3 + (50 - 1) × 4 = 203

因此，等差数列 3, 7, 11, 15, … 的第 50 项是 203。

通项公式为：an = 3 + (n - 1) × 4 = 4n - 1。

## math-06（math）

**题目**：解一元二次方程 2x² − 5x − 3 = 0，要求写出求解步骤。

### Model-A

要解一元二次方程 2x² − 5x − 3 = 0，我们可以使用求根公式：
x = [-b ± √(b² - 4ac)] / (2a)
其中，a、b 和 c 分别是方程中的系数。在这个例子中，a = 2，b = -5，c = -3。
首先，我们需要计算判别式 Δ = b² - 4ac：
Δ = (-5)² - 4 × 2 × (-3) = 25 + 24 = 49
因为 Δ > 0，所以方程有两个不同的实数解。
接下来，我们代入求根公式：
x = [5 ± √49] / (2 × 2) = [5 ± 7] / 4
因此，方程的两个解为：
x1 = (5 + 7) / 4 = 3
x2 = (5 - 7) / 4 = -1/2
所以，一元二次方程 2x² − 5x − 3 = 0 的解为 x1 = 3 和 x2 = -1/2。

### Model-B

\Delta = (-5)^2 - 4 \cdot 2 \cdot (-3) = 25 + 24 = 49
\]

\[
x = \frac{-(-5) \pm \sqrt{49}}{2 \cdot 2} = \frac{5 \pm 7}{4}

\[
x_1 = \frac{5 + 7}{4} = \frac{12}{4} = 3

\]

## math-07（math）

**题目**：本金 10000 元，年利率 5%，按复利计算，3 年后本息合计多少元？（结果保留两位小数）

### Model-A

根据复利公式，本息合计为：
A = P(1 + r/n)^(nt)
其中，A 为本息合计，P 为本金，r 为年利率，n 为每年计息次数，t 为时间（年）。
在这个问题中，P=10000 元，r=5%=0.05，n=1（按年计息），t=3 年。
代入公式得：
A = 10000(1 + 0.05/1)^(1*3)
= 10000(1.05)^3
≈ 11576.25 元
因此，3 年后本息合计约为 11576.25 元。

A = P(1 + r/n)^(nt)
其中，A 为本息合计，P 为本金，r 为年利率，n 为每年计息次数，t 为时间（年）。

```python
    # 初始化前两项
    a, b = 0, 1
    
    # 计算从第2项到第n项
    for _ in range(2, n + 1):
        a, b = b, a + b
    
    return b
```

### 为什么朴素递归的时间复杂度是指数级的

朴素递归实现斐波那契数列时，会重复计算很多子问题。例如，计算 `fib(5)` 时，会涉及到 `fib(4)` 和 `fib(3)` 的计算。而 `fib(4)` 又会涉及 `fib(3)` 和 `fib(2)` 的计算，而 `fib(3)` 则会涉及 `fib(2)` 和 `fib(1)` 的计算。这里可以看到，`fib(2)` 被计算了两次，`fib(1)` 被计算了三次，以此类推。这种情况下，计算 `fib(n)` 需要计算出所有 `fib(k)` (k < n)，导致时间复杂度为 O(2^n)，即指数级增长。

通过迭代方法，我们只需要一次遍历就能得到结果，因此时间复杂度为 O(n)。这种方法不仅提高了效率，还避免了递归调用栈过深的问题。

> **参考要点**：迭代 a,b=0,1 循环 n 次；朴素递归因重复子问题呈 O(φ^n) 指数增长（fib(k) 被重复计算多次）。

好的，下面是一个用 Python 实现的 `top_k_words` 函数，该函数接受一个字符串 `text` 和一个整数 `k`，并返回出现频率最高的前 `k` 个单词及其出现次数。

```python
import re
from collections import Counter

def top_k_words(text, k):
    # 将文本转换为小写，并移除所有非字母字符
    text = re.sub(r'[^a-zA-Z\s]', '', text).lower()
    
    # 使用空格分割文本为单词列表
    words = text.split()
    
    # 统计每个单词的出现次数
    word_counts = Counter(words)
    
    # 获取出现频率最高的前 k 个单词
    top_k = word_counts.most_common(k)
    
    return top_k

# 示例用法
text = "To be or not to be, that is the question."
k = 3
print(top_k_words(text, k))
```

在这个实现中：
1. 使用正则表达式 `re.sub(r'[^a-zA-Z\s]', '', text)` 来移除所有非字母字符。
2. 使用 `.lower()` 方法将文本转换为小写，以便忽略大小写差异。
3. 使用 `split()` 方法将文本按空格分割成单词列表。
4. 使用 `collections.Counter` 来统计每个单词的出现次数。
5. 使用 `most_common(k)` 方法获取出现频率最高的前 `k` 个单词及其出现次数。
