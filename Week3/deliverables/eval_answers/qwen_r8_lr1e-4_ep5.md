**题目**：鸡兔同笼：笼子里共有 35 个头、94 只脚，问鸡和兔各有多少只？请给出完整推理过程。

**模型回答**：

设鸡有 x 只，兔有 y 只。
根据题意，可以列出以下两个方程：
x + y = 35 （头的数量）
2x + 4y = 94 （脚的数量）
接下来，我们可以使用代数方法解这个方程组。
首先，我们可以将第一个方程变形为 y = 35 - x，然后将其代入第二个方程中：
2x + 4(35 - x) = 94
化简得：
2x + 140 - 4x = 94
整理得：
-2x = -46
解得：
x = 23
将 x 的值代入 y = 35 - x 中，得到：
y = 35 - 23 = 12
因此，鸡有 23 只，兔有 12 只。

**题目**：一个水池，甲管单独注水 6 小时注满，乙管单独注水 4 小时注满。两管同时打开，需要多少小时注满水池？

当两管同时打开时，它们的注水速度之和为 (V/6 + V/4) 升/小时。

所以，两管同时打开时，注满水池需要的时间为 V/(5V/12) = 12/5 = 2.4 小时。

因此，两管同时打开需要 2.4 小时注满水池。

**题目**：等差数列 3, 7, 11, 15, … 的第 50 项是多少？并给出通项公式。

**模型回答**：

这是一个等差数列，其中首项 a1 = 3，公差 d = 4。

根据等差数列的通项公式，第 n 项 an 可以表示为：
an = a1 + (n - 1)d

将 a1 = 3，d = 4 和 n = 50 代入上式，可得：
a50 = 3 + (50 - 1) × 4 = 203

因此，等差数列 3, 7, 11, 15, … 的第 50 项是 203。

通项公式为：an = 3 + (n - 1) × 4 = 4n - 1。

## math-06（math）

**题目**：解一元二次方程 2x² − 5x − 3 = 0，要求写出求解步骤。

**模型回答**：

要解一元二次方程 2x² − 5x − 3 = 0，我们可以使用求根公式：
x = [-b ± √(b² - 4ac)] / (2a)
其中，a、b 和 c 分别是方程中的系数。在这个例子中，a = 2，b = -5，c = -3。
首先，我们需要计算判别式 Δ = b² - 4ac：
Δ = (-5)² - 4 × 2 × (-3) = 25 + 24 = 49
因为 Δ > 0，所以方程有两个不同的实数解。
接下来，我们代入求根公式：
x = [5 ± √49] / (2 × 2) = [5 ± 7] / 4
因此，方程的两个解为：
x1 = (5 + 7) / 4 = 3
x2 = (5 - 7) / 4 = -1/2
所以，一元二次方程 2x² − 5x − 3 = 0 的解为 x1 = 3 和 x2 = -1/2。

## math-07（math）

**题目**：本金 10000 元，年利率 5%，按复利计算，3 年后本息合计多少元？（结果保留两位小数）

**模型回答**：

根据复利公式，本息合计为：
A = P(1 + r/n)^(nt)
其中，A 为本息合计，P 为本金，r 为年利率，n 为每年计息次数，t 为时间（年）。
在这个问题中，P=10000 元，r=5%=0.05，n=1（按年计息），t=3 年。
代入公式得：
A = 10000(1 + 0.05/1)^(1*3)
= 10000(1.05)^3
≈ 11576.25 元
因此，3 年后本息合计约为 11576.25 元。

**题目**：如果今天是星期三，那么 100 天之后是星期几？请给出计算方法。

**模型回答**：

首先，我们知道一周有7天，所以我们可以将100除以7，得到商和余数。
100 ÷ 7 = 14...2

这意味着100天等于14周加2天。因此，100天后是星期三加上2天。

从星期三开始，我们向前数2天：
星期三 + 1天 = 星期四

**题目**：用 Python 写一个函数 is_palindrome(s)，判断字符串是否为回文。要求：忽略大小写，忽略所有非字母数字字符（例如 "A man, a plan, a canal: Panama" 应返回 True），并给出至少 2 个测试用例。

**模型回答**：

这是一个使用 Python 编写的 `is_palindrome` 函数的示例：
```python
def is_palindrome(s):
 # 将字符串转换为小写
 s = s.lower()
 # 删除所有非字母数字字符
 s = ''.join(c for c in s if c.isalnum())
 # 检查字符串是否与其反转相等
 return s == s[::-1]
```
以下是两个测试用例：
```python
# 测试用例 1
s = "A man, a plan, a canal: Panama"
print(is_palindrome(s)) # 输出 True
# 测试用例 2
s = "race a car"
print(is_palindrome(s)) # 输出 False
```
在这个例子中，`is_palindrome` 函数首先将输入字符串转换为小写，然后删除所有非字母数字字符。然后，它检查字符串是否与其反转相等。如果相等，则字符串是回文，函数返回 True；否则，函数返回 False。

## code-02（code）

**题目**：用 Python 实现函数 fib(n) 返回斐波那契数列第 n 项（fib(0)=0, fib(1)=1）。要求：必须使用 O(n) 时间的迭代实现，禁止朴素递归，并说明为什么朴素递归的时间复杂度是指数级的。

**模型回答**：

下面是一个使用迭代方法计算斐波那契数列第 n 项的 Python 函数：

```python
def fib(n):
 if n == 0:
 return 0
 elif n == 1:
 return 1
 else:
 a = 0
 b = 1
 for i in range(2, n+1):
 c = a + b
 a = b
 b = c
 return b
```

这个函数使用了迭代的方法来计算斐波那契数列的第 n 项。它首先检查输入值是否为 0 或 1，如果是，则直接返回相应的值。否则，它初始化两个变量 `a` 和 `b` 分别为 0 和 1，然后使用一个循环从 2 到 n 迭代地计算斐波那契数列的第 n 项。在每次迭代中，它将当前项存储在变量 `c` 中，然后更新 `a` 和 `b` 的值以计算下一个项。

朴素递归的实现如下所示：

```python
def fib(n):
 if n == 0:
 return 0
 elif n == 1:
 return 1
 else:
 return fib(n-1) + fib(n-2)
```

这个函数使用了递归的方法来计算斐波那契数列的第 n 项。它首先检查输入值是否为 0 或 1，如果是，则直接返回相应的值。否则，它调用自身两次，分别计算斐波那契数列的第 n-1 项和第 n-2 项，并将它们相加以得到第 n 项。由于每次递归调用都会再次调用自身，因此这个函数的时间复杂度是指数级的。当 n 较大时，这个函数会非常慢，因为它需要进行大量的重复计算。

## code-03（code）

**题目**：下面的 Python 函数有一个隐蔽的 bug：

def add_item(item, result=[]):
    result.append(item)
    return result

请指出 bug 是什么、为什么会发生、如何修复。

**模型回答**：

这个函数的 bug 是在返回结果时，它并没有返回 `result` 列表的副本，而是返回了列表本身。这意味着如果在调用函数时传递了一个列表作为参数，那么在函数内部修改该列表也会改变外部列表的内容。

例如：
```python
my_list = [1, 2, 3]
print(add_item(4, my_list)) # 输出：[1, 2, 3, 4]
print(my_list) # 输出：[1, 2, 3, 4]
```
要修复这个问题，可以使用浅拷贝（shallow copy）来创建一个新的列表副本，而不是直接引用原始列表。可以使用 `copy()` 方法或切片操作来实现这一点。
修复后的代码如下：
```python
def add_item(item, result=None):
 if result is None:
 result = []
 result.append(item)
 return result
```
现在，当调用 `add_item()` 函数时，它会创建一个新的列表副本，并将新元素添加到副本中。这样，外部列表不会被修改。

## code-04（code）

**题目**：有一张订单表 orders(id, user_id, amount, created_at)。写一条 SQL：统计每个用户的订单总金额，只保留总金额大于 1000 的用户，按总金额从高到低取前 10 名。

**模型回答**：

```sql
SELECT user_id, SUM(amount) AS total_amount
FROM orders
GROUP BY user_id
HAVING total_amount > 1000
ORDER BY total_amount DESC
LIMIT 10;
```
这条 SQL 语句首先使用 `SUM()` 函数计算每个用户的订单总金额，并将结果与 `user_id` 进行分组。然后使用 `HAVING` 子句筛选出总金额大于 1000 的用户。最后使用 `ORDER BY` 子句按总金额从高到低排序，并使用 `LIMIT` 子句限制结果为前 10 名。

## code-06（code）

**题目**：用 Python 写一个函数 top_k_words(text, k)，统计一段英文文本中每个单词的出现次数（忽略大小写和标点），返回出现频率最高的前 k 个单词及其次数。

**模型回答**：

这是一个使用 Python 的 `collections` 模块来实现的函数：
```python
import re
from collections import Counter
def top_k_words(text, k):
 # 将文本转换为小写并删除标点符号
 text = re.sub(r'[^\w\s]', '', text.lower())
 # 使用空格分割文本并计算每个单词的出现次数
 words = text.split()
 word_counts = Counter(words)
 # 返回出现频率最高的前 k 个单词及其次数
 return word_counts.most_common(k)
```
这个函数首先使用正则表达式将文本转换为小写并删除所有标点符号。然后，它使用空格将文本分割成单词，并使用 `Counter` 类来计算每个单词的出现次数。最后，它返回出现频率最高的前 k 个单词及其次数。
例如，如果我们将这段文本传递给 `top_k_words` 函数：
```python
text = "The quick brown fox jumps over the lazy dog."
k = 3
result = top_k_words(text, k)
print(result)
```
输出将是：
```
[('the', 2), ('quick', 1), ('brown', 1)]
```
这表示在给定的文本中，“the” 是出现频率最高的单词，出现了两次；“quick” 和 “brown” 分别出现了一次。
