**题目**：鸡兔同笼：笼子里共有 35 个头、94 只脚，问鸡和兔各有多少只？请给出完整推理过程。

**模型回答**：

根据题意，可以列出以下两个方程：
x + y = 35 （头的数量）
2x + 4y = 94 （脚的数量）
将第一个方程变形为 y = 35 - x，代入第二个方程中，得到：
2x + 4(35 - x) = 94
化简得：2x + 140 - 4x = 94
整理得：-2x = -46
解得：x = 23
将 x = 23 代入 y = 35 - x 得到：y = 12
因此，鸡有 23 只，兔有 12 只。

**题目**：解一元二次方程 2x² − 5x − 3 = 0，要求写出求解步骤。

**模型回答**：

要解一元二次方程 2x² − 5x − 3 = 0，我们可以使用求根公式：
x = [-b ± √(b² - 4ac)] / 2a
其中，a、b、c 分别是方程中的系数，即 a = 2，b = -5，c = -3。
将这些值代入求根公式中，我们得到：
x = [5 ± √((-5)² - 4*2*(-3))] / (2*2)
x = [5 ± √(25 + 24)] / 4
x = [5 ± √49] / 4
x = [5 ± 7] / 4
因此，方程的两个解为：
x1 = (5 + 7) / 4 = 3
x2 = (5 - 7) / 4 = -1/2
所以，一元二次方程 2x² − 5x − 3 = 0 的解为 x1 = 3 和 x2 = -1/2。

A = P(1 + r/n)^(nt)

因此，3 年后本息合计为 11576.25 元。

**题目**：用 Python 写一个函数 is_palindrome(s)，判断字符串是否为回文。要求：忽略大小写，忽略所有非字母数字字符（例如 "A man, a plan, a canal: Panama" 应返回 True），并给出至少 2 个测试用例。

**模型回答**：

这是一个使用 Python 编写的函数，用于检查给定的字符串是否为回文：
```python
def is_palindrome(s):
    # 将字符串转换为小写，并删除所有非字母数字字符
    s = ''.join(c.lower() for c in s if c.isalnum())
    # 检查字符串是否与其反转相等
    return s == s[::-1]
```
以下是两个测试用例：
```python
# 测试用例 1
s = "A man, a plan, a canal: Panama"
print(is_palindrome(s)) # 输出：True
# 测试用例 2
s = "race a car"
print(is_palindrome(s)) # 输出：False
```
在测试用例 1 中，字符串 "A man, a plan, a canal: Panama" 被转换为 "amanaplanacanalpanama"，然后与它的反转 "amanaconalpamana" 相等，因此函数返回 True。
在测试用例 2 中，字符串 "race a car" 被转换为 "raceacar"，然后与它的反转 "raceacar" 相等，因此函数返回 True。

## code-02（code）

**题目**：用 Python 实现函数 fib(n) 返回斐波那契数列第 n 项（fib(0)=0, fib(1)=1）。要求：必须使用 O(n) 时间的迭代实现，禁止朴素递归，并说明为什么朴素递归的时间复杂度是指数级的。

**模型回答**：

以下是一个使用迭代实现的 Python 函数，用于计算斐波那契数列的第 n 项：

```python
def fib(n):
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        a = 0
        b = 1
        for i in range(2, n+1):
            c = a + b
            a = b
            b = c
        return b
```

这个函数使用了迭代的方法来计算斐波那契数列的第 n 项。它首先检查 n 是否为 0 或 1，如果是，则直接返回相应的值。否则，它初始化两个变量 a 和 b，分别表示斐波那契数列的前两项。然后，它使用一个 for 循环来计算斐波那契数列的第 n 项。在循环中，它将当前项存储在变量 c 中，然后更新 a 和 b 的值。最后，它返回 b 的值，即斐波那契数列的第 n 项。

朴素递归实现斐波那契数列的第 n 项的时间复杂度是指数级的。这是因为每次调用递归函数时，都会生成一个新的子问题，而每个子问题又会生成更多的子问题。例如，当 n = 5 时，递归函数将生成以下递归树：

```
fib(5)
|
v
fib(4) fib(3)
|
v v
fib(3) fib(2) fib(2) fib(1)
|
v v v v
fib(2) fib(1) fib(1) fib(0)
|
v v v v v v
fib(1) fib(0) fib(0) fib(1) fib(1) fib(0)
```

可以看到，递归树中共有 15 个节点，其中每个节点都代表了一个子问题。因此，递归函数需要进行 15 次递归调用才能计算出斐波那契数列的第 5 项。随着 n 的增大，递归树中的节点数量也会迅速增加，导致递归函数的时间复杂度呈指数增长。

## code-03（code）

**题目**：下面的 Python 函数有一个隐蔽的 bug：

def add_item(item, result=[]):
    result.append(item)
    return result

请指出 bug 是什么、为什么会发生、如何修复。

**模型回答**：

这个函数的 bug 是在返回结果时，它并没有返回一个新列表，而是返回了原始列表。这会导致在调用函数时，每次调用都会修改同一个列表，而不是创建一个新的列表。

例如，如果我们在调用函数时传入一个空列表作为参数，那么每次调用函数都会将新的元素添加到这个列表中，最终导致列表中的元素重复。

修复这个 bug 的方法是使用 `copy()` 方法来复制列表，这样每次调用函数都会创建一个新的列表，而不是修改原始列表。

修复后的代码如下：

```python
def add_item(item, result=None):
    if result is None:
        result = []
    result.append(item)
    return result
```

现在，每次调用函数都会创建一个新的列表，并将新的元素添加到这个列表中，不会影响到原始列表。

## code-04（code）

**题目**：有一张订单表 orders(id, user_id, amount, created_at)。写一条 SQL：统计每个用户的订单总金额，只保留总金额大于 1000 的用户，按总金额从高到低取前 10 名。

**模型回答**：

```sql
SELECT user_id, SUM(amount) AS total_amount
FROM orders
GROUP BY user_id
HAVING total_amount > 1000
ORDER BY total_amount DESC
LIMIT 10;
```
这条 SQL 语句首先使用 `SUM` 函数计算每个用户的订单总金额，并将结果与 `user_id` 进行分组。然后使用 `HAVING` 子句筛选出总金额大于 1000 的用户。最后使用 `ORDER BY` 子句按总金额从高到低排序，并使用 `LIMIT` 子句限制结果只返回前 10 条记录。

## code-05（code）

**题目**：以下 Python 代码的输出是什么？请解释原因：

funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])

**模型回答**：

这段代码的输出是 `[0, 1, 2]`。

让我们逐步分析代码：
1. `funcs` 是一个列表，其中包含三个 lambda 函数。每个 lambda 函数都接受一个参数 `i` 并返回它。
2. `for f in funcs` 循环遍历 `funcs` 列表中的每个 lambda 函数，并将它们存储在变量 `f` 中。
3. `[f() for f in funcs]` 使用列表推导式生成一个新的列表，其中包含每个 lambda 函数调用的结果。
4. 每个 lambda 函数都返回它所接收的参数 `i` 的值。因此，当循环遍历 `funcs` 列表时，它会依次调用每个 lambda 函数并返回它们的值。
5. 最终，列表推导式生成的列表是 `[0, 1, 2]`，因为每个 lambda 函数都返回它所接收的参数 `i` 的值，从 0 到 2。

## code-06（code）

**题目**：用 Python 写一个函数 top_k_words(text, k)，统计一段英文文本中每个单词的出现次数（忽略大小写和标点），返回出现频率最高的前 k 个单词及其次数。

**模型回答**：

这是一个使用 Python 编写的 top_k_words 函数，它接受一个字符串参数 text 和一个整数参数 k，并返回一个字典，其中键是出现频率最高的前 k 个单词，值是它们的出现次数。
```python
def top_k_words(text, k):
 # 将文本转换为小写并分割成单词列表
 words = text.lower().split()
 # 创建一个空字典来存储单词及其出现次数
 word_counts = {}
 # 遍历单词列表
 for word in words:
 # 如果单词已经在字典中，则增加其计数
 if word in word_counts:
 word_counts[word] += 1
 # 否则，在字典中添加该单词并将其计数设置为 1
 else:
 word_counts[word] = 1
 # 返回出现频率最高的前 k 个单词及其出现次数
 return dict(sorted(word_counts.items(), key=lambda x: x[1], reverse=True)[:k])
```
例如，如果我们将这段文本传递给 top_k_words 函数：
```python
text = "The quick brown fox jumps over the lazy dog."
print(top_k_words(text, 3))
```
输出将是：
```
{'the': 2, 'quick': 1, 'brown': 1}
```
这表示在给定的文本中，“the”、“quick”和“brown”是最常见的单词，它们的出现次数分别为 2、1 和 1。
